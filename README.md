# 集保自動投票助手 (TDCC Auto Vote Bot)

台灣集中保管結算所 (TDCC) 股東會電子投票自動化工具。自動登入、自動投票（棄權）、自動截圖留存投票紀錄。

---

## 功能說明

### 主程式：自動投票助手 (`vote_gui.py`)
- 自動開啟集保 e 投票網站並登入
- 自動掃描所有持股的股東會投票
- 對尚未投票的項目自動執行棄權投票
- 自動截圖保存每檔股票的投票紀錄
- 支援多頁分頁掃描
- 支援視覺辨識（圖像模板匹配）與座標定位兩種模式


---

## 環境需求

- **作業系統**：Windows 10/11
- **Python**：3.9 以上
- **瀏覽器**：Google Chrome（需安裝 ChromeDriver，或使用 Selenium 自動管理）

### 安裝 Python 套件

```bash
pip install pillow pyautogui pynput selenium pyperclip opencv-python
```

## 設定與憑證配置

### 1. 身分證字號（必要）

啟動程式後，在 GUI 介面的「身分證號」欄位中輸入你的身分證字號。此資訊**僅用於登入集保 e 投票網站**，不會被儲存至任何檔案中。

> **注意：請勿將身分證字號寫死在程式碼中。** 每次啟動時手動輸入即可。

### 2. 券商憑證（必要）

登入集保 e 投票網站需要**券商網路下單憑證**（數位簽章）。請確認：
- 你的電腦已安裝券商提供的憑證元件
- 瀏覽器能正常存取該憑證
- 程式會自動選擇「券商網路下單憑證」選項

### 3. 座標定位設定 (`config.json`)

首次使用時，程式會引導你用滑鼠定位以下 7 個 UI 元素的螢幕座標：

| 步驟 | 說明 |
|------|------|
| 1 | 首頁右上角「登入」按鈕 |
| 2 | 身分證字號輸入框 |
| 3 | 憑證種類下拉選單 |
| 3_option | 下拉選單中的「券商網路下單憑證」選項 |
| 4 | 登入表單的「登入」按鈕 |
| 4_confirm | 重複登入確認框的「確認」按鈕 |
| 5 | 瀏覽器權限提示的「允許」按鈕 |

定位結果會自動儲存至 `config.json`。如需重新設定，可點擊 GUI 中的「開始定位」按鈕。

已提供 `config.example.json` 作為格式參考，首次使用時可複製為 `config.json`：
```bash
cp config.example.json config.json
```

### 4. 視覺模板（可選，建議設定）

除了座標定位，程式也支援**圖像模板匹配**來辨識 UI 元素。在 GUI 中點擊「視覺模板管理」區域的各步驟按鈕，拖曳框選對應的畫面元素即可。

模板圖片會儲存在 `voting_records/` 資料夾中，檔名如 `step1.png`、`step2.png` 等。

## 使用方式

### 方法一：透過 BAT 檔啟動（推薦）

雙擊 `快速啟動.bat` 即可開啟 GUI 介面。

### 方法二：命令列啟動

```bash
python vote_gui.py
```

### 操作流程

1. **輸入身分證字號**：在「身分證號」欄位輸入（預設為遮罩顯示，點擊眼睛圖示可切換）
2. **座標定位**（首次使用）：點擊「開始定位」，依照提示依序移動滑鼠到各 UI 元素位置並按 F10
3. **開啟網頁**：點擊「1. 開啟網頁 (自動登入)」，程式會自動開啟 Chrome 並執行登入流程
4. **選擇憑證**：登入過程中會需要你在券商憑證選擇視窗中確認
5. **開始自動執行**：登入完成後，點擊「2. 開始自動執行」，程式會自動：
   - 掃描所有持股的股東會投票
   - 對未投票的項目執行棄權投票
   - 截圖保存投票紀錄至「截圖儲存區」資料夾
6. **停止**：隨時點擊「停止運作」按鈕即可中止

## 注意事項

- 本程式使用 Selenium 控制 Chrome 瀏覽器，執行時請勿手動操作該瀏覽器視窗
- 座標定位會因螢幕解析度和縮放比例改變而失效，更換螢幕設定後請重新定位
- 程式預設對所有議案執行「棄權」投票，如需修改投票策略請編輯 `tdcc_vote_bot.py`
- 投票截圖儲存於「截圖儲存區」資料夾，建議定期備份
